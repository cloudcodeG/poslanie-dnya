# Послание дня — виджет на iPhone

Виджет для **Scriptable** (бесплатное приложение из App Store). Показывает сегодняшнее послание дня на главном экране или на экране блокировки.

Каждый день — своё послание (выбирается по числу дня, детерминированно). На виджете видна дата и номер дня — так сразу понятно, что это послание именно сегодняшнее.

## Установка (2 минуты)

1. Поставь **Scriptable** из App Store (бесплатно).
2. Открой Scriptable → нажми **«+»** (новый скрипт) → выбери «Пустой».
3. Вставь весь код из файла **`spirit-widget.js`** (замени содержимое скрипта).
4. Нажми ▶️ (запустить) — увидишь превью виджета и сегодняшнее послание. Значит, всё работает.
5. Переименуй скрипт, например в **«Послание дня»** (кнопка с иконкой гаечного ключа сверху).

## Виджет на главный экран

1. Удерживай палец на свободном месте домашнего экрана → нажми **«+»** (добавить виджет).
2. Найди **Scriptable** и выбери размер (рекомендую **Средний** или **Большой** — текста много).
3. После добавления — **нажми на виджет** → **Выбрать скрипт** → **«Послание дня»**.
4. Опционально: в этом же меню можно настроить частоту обновления.

## Виджет на экран блокировки

1. Удерживай палец на экране блокировки → **«Настроить»**.
2. Выбери область → **«+»** → найди **Scriptable**.
3. Добавь (лучше прямоугольный виджет — в круглый поместится мало текста).
4. Нажми на виджет → скрипт **«Послание дня»**.

## Смена традиции

В начале кода `spirit-widget.js` есть переменная:

```js
const TRAD = ""; // "" = каждый день новая традиция по кругу
```

Можно зафиксировать одну:
```js
const TRAD = "science";      // Наука
const TRAD = "runes";        // Руны (скандинавские)
const TRAD = "slavic-runes"; // Руны славянские
const TRAD = "bible";        // Библия
const TRAD = "mantras";      // Мантры
const TRAD = "quran";        // Коран
```

После смены — запусти скрипт ещё раз (▶️), чтобы проверить.

## Как работает

- Виджет скачивает данные с сайта **poslanie-dnya.vercel.app** (тот же контент, что в приложении).
- Послание выбирается по номеру дня: `день % количество` — поэтому оно «случайное», но всегда одинаковое весь день.
- Нажатие на виджет открывает это же послание в приложении.
- Без интернета виджет покажет ошибку — но в обычной жизни iPhone обновляет его по расписанию.
